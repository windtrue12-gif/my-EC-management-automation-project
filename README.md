📂 【ポートフォリオ】ECモール一元管理 ✕ クラウド同期システム

■ 概要
複数ECモール（Yahoo!ショッピング、楽天市場、Amazon等）を運営する個人事業者向けの、在庫連動および売上集計の自動化・クラウド化プロトタイプシステム。
デスクトップ管理（CSV）による「データ消失リスク」と「転記手作業の多さ」を根本から解決するシステムを構築しました。

■ システム構成・アーキテクチャ
・開発言語/環境: Python 3.x, Pandas
・ハブ（データベース）: Google スプレッドシート
・利用API・認証: Yahoo!ショッピングAPI / Google Sheets API / Google Drive API (GCPサービスアカウントによるセキュリティ認証)

■ 実装機能・技術的ポイント
1．クラウド連携＆高速一括処理ロジック
APIを介してGoogleスプレッドシートとPythonをシームレスに連携。API通信のオーバーヘッドを最小限に抑えるため、一度全データをPandasのDataFrameに一括で吸い上げ、メモリ上で高速に計算処理を行った後、クラウドへ一括上書き同期する設計にしています。

2．4シート同時ドミノ倒し在庫連動
「モールで注文が発生した」というイベントをトリガーに、システムが自動で【商品マスタ】【在庫管理】【注文履歴】【売上集計】の4つの独立したシートの在庫引き算・売上加算・履歴追記を、矛盾なく一瞬で実行します。

3．リアルタイム集計ダッシュボード（フロントエンド）
スプレッドシート側に管理者用ダッシュボードを構築。
・QUERY関数: 注文データから「出荷待ち」のデータのみを動的にリアルタイム抽出。
・ピボットテーブル＆グラフ: モール別の売上・粗利金額を自動集計し、可視化グラフへ連動。
Python側からデータが同期された瞬間、画面上の集計表やグラフが一切の手作業なしで完全自動更新される仕組みを実現しました。

■ 解決できる顧客の課題
・BCP対策: データをクラウド化するため、PC破損時のデータ完全損失リスクをゼロにします。
・業務効率化: 各モールの在庫書き換え、CSVの転記加工、毎日の売上集計作業がすべて自動化され、日々のルーティンワークを「0分」に圧縮可能です。
・権限管理への布石: Googleの標準機能をベースにしているため、将来的なスタッフ追加時にも「閲覧のみ」「編集可能」といったアクセス権限の切り分けが安全に行えます。
